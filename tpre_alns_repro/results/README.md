# Results directory

Place original run-level outputs here, not manually reconstructed summary numbers.

Recommended minimum fields per run:

- experiment_id
- code_commit
- data_manifest_sha256
- method
- customer_scale
- base_instance_id
- algorithm_seed
- optimization_scenario_seed_set
- out_of_sample_scenario_seed_set
- evaluator_checkpoint_sha256
- total_cost
- scenario_dependent_cost_cvar
- infeasible_scenario_ratio
- cpu_seconds
- complete_scenario_evaluations
- created_at_utc
