# Provenance

This code was reconstructed from the methodological descriptions and parameter tables in the manuscript and S1 Appendix. It is intended as a transparent reference implementation and repository scaffold.

The generated example data were created after the manuscript using the seed recorded in each file. They are not the original benchmark instances, scenario files, route pool, training data, checkpoint, or run-level results used to calculate the manuscript's reported values.

Before claiming exact reproducibility, the authors should replace or supplement this scaffold with the original experiment artifacts and document any difference between the clean-room implementation and the original code.
